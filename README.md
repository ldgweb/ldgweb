Full stack developer. I'm building my own way of working with AI agents, one tool at a time: they read the context, they propose, I decide.

I use these tools every day, and they change as my way of working does.

- **[Beynt](https://beynt.com)**: the memory of all my work. The docs of every project, my toolbox of commands, ideas and drafts. Every AI app I connect over MCP reads it before it starts and proposes changes; I approve what stays.
- **[Agent Review Studio](https://github.com/ldgweb/agent-review-studio)**: how I review code written by agents. Every change with the request behind it, and a review the agent can act on. Windows app and the `ars` CLI.
- **[Appunto](https://github.com/ldgweb/appunto)**: quick notes, handwriting and a scratch page that is never saved, one shortcut away from any app. Windows, macOS and Linux.
- **Edizium**: where I code and run my servers with AI agents, several sessions side by side. In daily use, not public yet.
